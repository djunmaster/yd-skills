# Profile Schema

全局 Profile 是用户长期偏好的唯一存储位置，不放在任何 Skill 文件夹里。

## 文件

```text
C:/Users/liuyd/.codex/design-profiles/universal-ui.md
```

在其他机器上使用 `%USERPROFILE%/.codex/design-profiles/universal-ui.md`；本文件中的用户名路径只是当前机器的默认值。

## 必需小节

| 小节 | 内容 | 更新规则 |
| --- | --- | --- |
| `全局规则` | 可复用的 UI 约束 | 只从多次一致的使用记录归纳 |
| `被否决方向` | 用户明确讨厌的方向 | 保留日期与理由 |
| `项目使用记录` | 各项目的选择历史 | 只追加，不改写历史 |
| `归纳说明` | 规则变化日志 | 保留废弃原因 |

## 记录字段

| 字段 | 说明 |
| --- | --- |
| 日期 | 客户端日期 |
| 项目 / 场景 | 产品类型或页面类型 |
| 选择 | 最终布局、风格或密度 |
| 理由 | 用户原意的一句话归纳 |
| 归属 | global、project、one-off |

## 判断规则

- “以后”“总是”“我讨厌” → global 候选。
- “这个项目”“这个品牌”“当前技术栈” → project。
- “这次先”“为了演示”“临时” → one-off，不写文件。
- 同一方向至少出现 2 次且没有反例，才提升为全局规则。
- 项目记录可以进入全局 Profile 的历史区，但不能直接进入全局规则。
