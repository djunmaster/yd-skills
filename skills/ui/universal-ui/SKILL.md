# Universal UI (v2.0)

## 1. 定位与不可突破的工程边界
- **只交付用户指定的 UI 区块或页面**：保留目标项目既有路由、导航、框架、数据接入与基础组件库；不复制演示页外壳，不引入第二套基础 UI 库，不做全局样式重置。
- **真实数据驱动与完整状态**：图表、指标与表格保持统一筛选范围和统计口径；按需覆盖加载骨架屏、空态、无匹配、异常与可恢复重试路径；演示数据必须明确标注。
- **读写分离**：执行前按优先级读取偏好：**本次明确要求 > 当前项目 `DESIGN.md` > 全局 Profile（`~/.codex/design-profiles/universal-ui.md`）> 默认基线**；本 Skill 只读不写，沉淀偏好交由 `$ui-preference-ledger`。

## 2. 执行前工作流（含行业标杆调研）
1. **局部精修快路径**：仅修改已有区块时，读取目标代码与最匹配的单个模板/色盘，直接执行并验收。
2. **新页面 / 新领域标杆调研（核心升级）**：
   - 设计新行业或新工具界面前，先调研该领域 2–3 个公认的标杆产品（例如：AI Agent 工作台参考 Codex Desktop / Magpie / Pi；金融司库参考 Mercury / Stripe；能源监控参考 Tesla Energy / Vercel；知识库参考 Notion / Craft；个人健康参考 Apple Health / Things 3）。
   - 提炼标杆产品的 **外壳重量（Chrome Weight）、视觉重心、灰阶冷暖与核心微交互**，只学结构与交互逻辑，不做像素级品牌复刻。
3. **风格与色盘收敛**：
   - 未锁定时提供 **3 个可区分候选**（稳妥推荐 / 偏好候选 / 特色候选），用户确认后锁定唯一主导色盘，禁止随机拼接。
   - 支持从 `references/style-library.md` 的 **6 套克制高美感色盘**（含原版 `Neutral Core`）中按场景匹配，并与 3 档正交密度（`Airy / Balanced / Compact`）组合。
4. **图表与可视化专项**：凡涉及折线、柱图、KPI 带、时间线、拓扑流或进度条，必须遵守 `references/dataviz-craft.md` 的焦噪分离与直接标注规范。
5. **双轨实测验收**：交付前对照 `references/visual-quality.md` 在 `1440px / 1024px / 390px` 与浅/深双主题下实测打分，总分 ≥ 85 分且未触发一票否决项方可交付。

## 3. 核心视觉与交互硬规范
- **文字与排版克制**：7 级光学字阶（12.5 / 14 / 16 / 20 / 26 / 36px），大字收紧负字距（`-0.02em ~ -0.03em`），禁止 `< 12px` 元数据与 `Thin/Light` 细字重；所有数字与货币强制 `font-variant-numeric: tabular-nums`。
- **控件精致度底线**：禁止在现代工作台中使用未经样式化的粗糙原生 `<select>` 下拉框，一律使用自定义毛玻璃/雾面 Popover 弹出菜单（支持键盘 `Escape` 关闭、清晰选中态与双行说明）；按下不位移，键盘焦点清晰可见。
- **色彩克制纪律**：页面 90% 以上保持中性画布与表面，仅在主操作、焦点与关键数据序列使用克制强调色；红色仅留给真正需要立即处理的异常或超限项，状态必须配合文字表达。
