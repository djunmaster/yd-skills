# 布局模式

按任务选择布局，而不是按视觉偏好先选布局。每个模式都可以从五个模板取局部组件组合，不需要复制整页。

| 模式 | 适用任务 | 核心结构 | 组件来源 |
| --- | --- | --- | --- |
| 数据分析页 | 对比指标、解释趋势、下钻明细 | 标题区、周期筛选、指标带、主图表、明细表 | `assets/analytics.html` |
| 监控排障页 | 找异常、定位时间点、查看状态 | 筛选栏、服务状态、时间线、可用率摘要 | `assets/monitoring.html` |
| 配置控制页 | 管理提供方、开关服务、检查状态 | 分组标题、配置行、状态标签、测试操作 | `assets/gateway.html` |
| 记录管理页 | 搜索、筛选、排序、批量查看 | 工具栏、搜索筛选、可排序表格、行操作 | `assets/crm.html` |
| 账务流程页 | 看摘要、处理逾期、追踪状态 | 提醒条、收款摘要、进度、账单表 | `assets/saas.html` |

## 常见扩展产品

### AI Agent 工作台

结构：

```text
左侧：任务 / 会话列表
中央：消息流 + 执行轨迹 + 工具输出折叠
右侧：文件、产物或任务详情，按需打开
底部：输入区 + 上下文附件 + 运行控制
```

要求：

- 会话、运行、工具调用和成果是不同对象，不能混成一个列表。
- 暂停、停止、恢复、请求输入、授权和未知结果分别表达。
- 只有真实委托时显示子 Agent，不默认制造固定成员。
- 长输出先摘要后展开，避免把中央区变成日志墙。

### 笔记与知识库

结构：

```text
左侧：层级目录
中央：正文编辑或阅读
右侧：属性、反向链接、任务或引用
顶部：面包屑、同步状态、命令入口
```

要求：

- 阅读优先，正文行高和列宽优先于装饰。
- 层级结构清楚，拖拽和键盘路径同时可用。
- 长文档优先目录和折叠，不用卡片墙切碎内容。

### 小工具

结构：

```text
输入区：用户要处理的原始内容或参数
结果区：立即更新、可复制、可回滚
辅助区：历史记录、预设、设置
```

要求：

- 首屏能完成一次完整任务。
- 结果反馈靠近触发操作，不把反馈放到远处。
- 工具栏紧凑，但正文和元数据不低于 12px。

### 桌面型效率工具

结构：

```text
顶部：轻量命令栏
左侧：对象列表或模块导航
中央：当前对象主工作区
右侧：上下文详情，可折叠
```

要求：

- 键盘优先，常用操作有可发现快捷键。
- 状态栏持续显示同步、运行或错误信息。
- 窄屏优先保留中央工作区，不强行保留三列。

## 布局决策规则

- 比较对象用表格；理解过程用时间线；看总量和趋势用图表；配置对象用设置行。
- 页面最多一个主操作、一个强调色、一个视觉记忆点。
- 图表回答一个问题；两个无关问题分成两个图表或两个区块。
- 数字右对齐，单位随标签或随数字一致，不在同一页面混用。
- 空间不足时先减少次要列，再考虑横向滚动；整页禁止横向溢出。
- 移动端不要压缩成不可用的三列；先保留当前任务，再保留导航和详情。
