# Layout Atlas 目录

[layout-atlas.html](../assets/layout-atlas.html) 展示 12 类页面 × 3 个方案，共 36 个页面级布局。它回答“结构怎么摆、层级怎么分、颜色放进页面后是否加分”，不是单独评价色板。

## 使用方式

1. 先按产品类型筛选布局。
2. 每类只比较三个方案：稳妥、紧凑、个性。
3. 先确认首屏结构和任务路径，再评价色彩与风格。
4. 用户要求沉淀选择时，交给 `$ui-preference-ledger`；实际实现时从五个模板取可用组件。

## 判断顺序

- 首屏是否回答用户最关心的问题。
- 主要操作是否清楚，且不超过一个主按钮。
- 数据、状态、说明是否有固定位置。
- 密度是否适合使用频率。
- 颜色是否只用于层级、状态和轻强调。
- 窄屏是否保留当前任务，而不是硬压缩三栏。
