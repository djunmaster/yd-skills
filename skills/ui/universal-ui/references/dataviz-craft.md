# 数据可视化美学规范（DataViz Craft）

凡页面包含指标带、折线、柱图、拓扑图、状态时间线或进度条，必须遵守以下 5 条硬准则：

1. **焦噪分离（Focus vs Context）**：单张图表最多 1–2 条主序列使用强调色，对比基线、历史同期或其余维度一律退为中性灰（`--viz-context`）或虚线，严禁 6–8 色彩虹混战。
2. **直接标注优先于独立图例**：优先在曲线终点或柱体空白侧直接标注名称与数值，减少视线在顶部/底部图例与图表之间来回跳转。
3. **去网格化与空气感**：去掉垂直网格线与外层方框，仅保留 2–4 条极淡水平参考线（`--viz-grid`）；折线下方仅允许 8%–16% → 0% 的单一线性透明渐变。
4. **结论型标题 + KPI 锚点**：图表上方用一句简短结论代替干巴巴的字段名，右侧配主指标大数字锚点；悬停时用细准星（crosshair）显示精确同比/环比。
5. **领域特色组件模式**：
   - 能源 / 资金流向：极简拓扑节点图（回答“从哪来、到哪去”）。
   - 服务 / 设备可用率：20–30 格脉冲状态条（正常低饱和绿、降级琥珀、故障红，悬停看详情）。
   - Agent / 链路耗时：水平瀑布甘特条 + 分段上下文构成条。
