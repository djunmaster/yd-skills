# Style Atlas 目录

[style-atlas.html](../assets/style-atlas.html) 用同一个小界面展示 56 个风格。它优先回答“看起来是什么”，而不是用长文案解释审美。

## 使用方式

1. 先看整页或按家族筛选。
2. 记下最多 5 个喜欢方向、最多 3 个明确讨厌方向。
3. 回到 [style-selection.md](style-selection.md)，把被选择的方向压缩为三个候选。
4. 用户要求沉淀选择时，交给 `$ui-preference-ledger`。

## 用户偏好基线

- 简洁优先，不选强光效、重渐变和大面积装饰。
- 文案克制，样张只保留适用和避免两行。
- 颜色用于层级和状态，不做视觉表演。
- 同一项目最多选择一个主导风格；混合时只允许一个辅助风格。
