# 风格库

这些风格用于目标项目的可选方向。`Neutral Core` 是默认基线，但不是所有产品的唯一答案。同一项目内只锁定一个风格；混合时先写出各风格贡献的部分，避免随机拼接。

## Neutral Core

**适用**：数据后台、管理控制台、内部工具、当前 Universal UI 项目。

**气质**：冷静、数据优先、克制。

**特征**：

- 柔和中性画布，细分隔线，少量紫色焦点与轻强调。
- 浅色模式主操作为石墨，深色模式为反白。
- 正文 14px，元数据不低于 12px，行内控件 32px，表格行约 44px。
- 卡片只承载独立对象，不做卡片墙或嵌套卡片。

**不适合**：强品牌表达、长文阅读、艺术或文化内容。

## Quiet Workspace

**适用**：笔记、知识库、文档、研究工具。

**气质**：安静、可长时间阅读、少干扰。

**特征**：

- 更宽的正文列距和更稳定的行高。
- 弱化边框，用留白和标题层级区分内容。
- 少量温润表面色，状态提示靠文字和图标而不靠强底色。
- 侧栏与正文有明确边界，但导航视觉弱于内容。

**不适合**：高频监控、密集表格、需要一眼识别状态的运维页。

## Technical Console

**适用**：Agent 工作台、终端、调试器、运行日志、系统工具。

**气质**：清晰、专业、可追溯。

**特征**：

- 中央内容优先，工具输出按时间线组织。
- 等宽数字与等宽代码，但正文不全部等宽。
- 状态层级明确：等待、运行、需要输入、失败、已完成、未知。
- 深浅主题下都保持低噪声，不用霓虹色铺满界面。

**不适合**：消费级内容、轻量生活工具、需要柔和亲和力的页面。

## Precision Data

**适用**：财务、分析、运营报表、交易明细。

**气质**：精确、紧凑、可靠。

**特征**：
- 数字和货币强对齐，单位固定在列头或单位行。
- 高信息密度，但保留清晰的行分隔和悬浮态。
- 图表克制，优先趋势、分布和异常，不做装饰性图形。
- 正数、负数、中性值有一致颜色语义。

**不适合**：品牌官网、故事叙述、空态引导为主的页面。

## Soft Product

**适用**：个人效率工具、轻消费产品、引导型小工具。

**气质**：友好、轻盈、低压力。

**特征**：
- 更柔和的表面色和更大的圆角，但阴影仍克制。
- 主操作明显，辅助操作安静。
- 空态提供下一步动作，不只是插画。
- 动效用于确认、展开和反馈，不做整页滚动表演。

**不适合**：高频专业操作、密集数据、需要严肃感的金融或安全页面。

## Editorial Focus

**适用**：产品介绍、内容站、说明文档首页、发布页。

**气质**：有观点、排版主导、阅读舒适。

**特征**：
- 标题层级和版式是记忆点，而不是渐变和光效。
- 每屏只讲一个主题，图片或产品截图有明确职责。
- 正文列宽受控，段落节奏稳定。
- 只在关键位置使用强调色。

**不适合**：管理后台和需要高密度的工具界面。

## Compact Utility

**适用**：桌面小工具、转换器、批量处理器、效率插件。

**气质**：直接、快、少废话。

**特征**：
- 首屏完成输入、动作和结果。
- 控件贴近相关数据，设置默认折叠。
- 尺寸紧凑但焦点与可读性不受损。
- 操作反馈就地出现，历史记录可恢复。

**不适合**：需要品牌叙事、长文阅读或复杂探索的页面。

## Dark Command

**适用**：监控、运维、开发控制台、夜间使用的操作型工具。

**气质**：专注、稳定、可控。

**特征**：
- 深色表面分层清楚，不把所有区块压成同一层。
- 状态色用于异常和关键路径，不做霓虹装饰。
- 深色主操作使用高对比反白，不是紫色渐变。
- 文本、分隔线、图表在深浅主题下有等价语义。

**不适合**：强光环境优先的表单录入、面向大众的轻量页面。

## 混合规则

- 可选混合：`Neutral Core + Technical Console`、`Quiet Workspace + Compact Utility`、`Precision Data + Neutral Core`。
- 不建议混合：`Editorial Focus + Technical Console`、`Soft Product + Precision Data`。
- 混合时只能有一个风格主导；另一个只贡献密度、图表或空态等局部规则。
