## 二、正交配置轴
- **信息密度（Density）**：`Airy`（展示/阅读/健康，大留白） / `Balanced`（默认应用，44px 表行） / `Compact`（专业监控/配置台，高密度不损可读性）。
- **外观主题（Appearance）**：`light` / `dark` 语义完全等价，深色模式下允许 `1px` 顶部微高光（`--specular`）替代厚重阴影。
- **材质纪律**：正文与数据区永远保持纯实底高对比；仅允许在顶部粘性导航栏或自定义 Popover 弹出菜单使用克制的毛玻璃透明效果。
