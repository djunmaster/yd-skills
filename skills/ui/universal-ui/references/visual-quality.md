# 区块验收清单

| 项目 | 分值 | 检查 |
| --- | ---: | --- |
| 范围与层级 | 25 | 未重做宿主外壳。标题、筛选、关键信息和明细的顺序与所选模板一致。 |
| 视觉一致性 | 25 | 深浅主题等价，分隔线、字重、主操作、状态色与参考一致；无嵌套卡片或装饰干扰。 |
| 密度与窄屏 | 20 | 1440 / 1024 / 390px 下无整页横向溢出。数字对齐，元数据至少 12px，长值完整可读。 |
| 状态与数据 | 15 | 筛选和数据口径一致；适用的空、无匹配、失败和恢复均有可操作路径；演示如实标注。 |
| 控件与键盘 | 15 | 名称、状态、焦点可见；按下无位置跳动；状态不只靠颜色。新增浮层实测 Escape、焦点约束和返回。 |
