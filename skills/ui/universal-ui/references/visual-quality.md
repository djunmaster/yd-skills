# 视觉质量与双轨验收清单（v2.0 · 满分 100 分，及格线 85 分）

仅针对本次修改或新建区块，基于浏览器实测打分（禁止仅凭静态读码给满分）。

## 一、工程可靠性底线（60 分 · 低于 52 分直接驳回）
1. **范围与宿主边界（20 分）**：未破坏宿主外壳、导航与全局样式；组件信息层级与任务路径清晰。
2. **密度与三端适配（20 分）**：`1440px / 1024px / 390px` 均无整页横向溢出；元数据 ≥ 12px；数字强制 `tabular-nums` 等宽对齐。
3. **状态与键盘可用性（20 分）**：加载/空态/无匹配/失败恢复路径完整；焦点可见、按下无位移；弹出菜单支持 `Escape` 关闭与焦点返回；状态不单靠颜色表达。

## 二、审美与可视化质感（40 分 · 低于 32 分需返工）
4. **光学层级与文字克制（20 分）**：浅/深主题语义等价；靠留白、字阶与 1px 细线建立层次而非粗框堆叠；顶栏与侧栏外壳克制无冗余徽章；文字精炼无废话。
5. **图表叙事与微交互质感（20 分）**：图表满足焦噪分离与直接标注；无粗糙原生 `<select>` 下拉框；悬停提示与开关反馈顺滑自然。

## 三、一票否决项（触发任一条即不通过）
- 全页横向溢出或无法用键盘完成主流程
- 文本对比度不足（正文 < 4.5:1）或使用 `< 12px` / `Thin` 细字重
- **AI 廉价感黑名单**：出现蓝紫霓虹渐变按钮、卡片套卡片、彩色 Emoji 充当业务 UI 图标、8 色彩虹折线图、粗糙未美化的原生 `<select>` 下拉框
- 把演示假能力包装成真实已接通能力
