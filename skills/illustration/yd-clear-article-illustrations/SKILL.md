# 清晰文章配图

以讲清内容为先，使用用户确认的清爽手绘知识图解风格，创作文章与培训插图。适合时一页讲清一个知识点；人物是可选的，不设固定吉祥物。用户对本次图像的明确要求优先于以下默认值。

## 默认输入与风格

用户通常只需提供想表达的主题、正文、数据或流程。将这些输入作为内容依据，自动提炼结论、对象、关系和必要标签；不要要求用户每次补充画风、配色、布局或人物设定。

每次默认沿用下方视觉规范与首要参考图。用户本次明确提出的画幅、标题、必须出现的元素等具体要求照常执行；只有用户明确要求改变视觉风格时，才覆盖相应的默认风格设定。内容材料中提到的外观或颜色若属于主题本身，不要误当成改变整张图画风的指令。

## 首要视觉基准

[用户确认的整体参考图](references/personal-style-anchor.png) 是首要基准，涵盖线条、颜色、中文排版、流程和分区，不仅是人物参考。构思与出图时结合 [风格参照说明](references/style-guide.md)；条件允许时先查看该图。工具允许以图片为参考时，遵守该工具对生成与编辑的使用规则，将它作为视觉基准；不能传图时，把下述具体特征写入提示词。

## 先把内容变成画面

1. 从材料中提取受众、用途、原文依据、一句核心结论，以及必要的对象和关系。区分来源事实、示意和推断，不添加文章没有的结论、数据或保证。
2. 按内容选择一种清晰的组织方式：流程/因果、前后对比、结构层次、场景或具体动作。给抽象概念找与其功能对应的具体物件或动作作为认知锚点；隐喻不能改变事实关系。并非每张图都需要箭头和卡片。
3. 规划视觉阅读顺序，保留解释这个重点所需的节点和连接。一个重点可以有多个步骤；内容过载时拆图，避免缩字硬塞。文章插图可比培训页更少文字；画幅和细节服从发布场景与用户要求。
4. 明确判断人物是否有助于表达关系、关键动作、视角或情绪。若没有帮助，用物件、场景或结构图表达；不要自动增加人物、吉祥物或机器人。

## 画面风格

- **线条与底色：**白色或近白背景；清晰、顺滑、略有手绘感的黑色轮廓，线条饱满、粗细相近，形状简练，留白充足。人物和图形的笔触协调；不要把所有轮廓加粗成浓重的卡通描边。不要默认使用密集排线、复古纸纹、厚重阴影或三维效果。
- **橙蓝强调：**黑白为主，少量明亮橙色和蓝色可以同时出现，例如橙色主流程箭头或下划线、蓝色关键关系箭头或勾选标记。颜色的含义应在同一图内一致；重点醒目但不铺满彩色背景。
- **标题与分区：**中文标题和小标题清楚、醒目，常用黑色粗体无衬线字；副标题和图形标签更小，标题不过度挤占图示空间。培训图可采用标题区、上方主要流程、下方简短补充区，并用细线区分。优先以留白组织流程，通常不把每一步都装进巨大的圆角卡片或胶囊标题。按内容调整分区和步骤，不把参考图的具体版式当成所有图片的硬模板。
- **图形与人物：**使用直观的简笔物件、简洁框线、箭头、勾选标记等表达关系；人物仅在帮助理解动作、关系、情绪或情境时加入，大小不压过内容。可以从杂志漫画、粗笔涂鸦、冷面线描借鉴人物气质，但应融入首要基准的整体线条与排版。人物身份和动作随主题变化，不重复固定角色。
- 一个知识点可包含必要的流程与简短补充，确保阅读方向、关键信息和缩小后的文字清楚。避免无关装饰、密集小字、彩色大底、与信息无关的卡片、过分幼态的角色及大段重复文案。

## 提示词与参考图

以下是 Skill 根据用户材料自动组织的内部生成提示词结构，不是要求用户填写的表单。把用户提供的内容填入内容相关项，并自动附上本 Skill 的固定视觉基准；除非用户明确要求改变风格，不要再询问或要求用户重复描述画风。

实际出图前，把以下内容组织成简洁且具体的生成提示词：

```text
用途和画幅：[文章插图 / 培训图；横向或其他]
核心结论：[一句话]
必须准确表现的对象、关系及阅读顺序：[具体描述]
画面构思：[与结论对应的主体、动作和布局；说明是否需要人物]
画法与排版：[参照图的白底黑线、橙蓝点缀、文字层级和与内容匹配的分区]
文字：[逐字列出必要的短标题和标签；不需要则写无文字]
避免：[会妨碍本图理解的装饰、错画或无关元素]
```

提示词只写当前图需要的约束；保留参考图的整体视觉语言和清晰的阅读节奏，根据主题重新组织文字、人物和具体构图，不把参考图中的人物、动作或原文字当成固定内容。对于一组图，保持线条、颜色、文字层级和信息密度协调，让各图依据内容变化。

文字以可读的短标签为主，避免同一意思在标题、编号和结论条反复出现。需要精确中文时，逐项核对生成结果；若当前环境允许使用可靠方式排字，可预留位置后处理，否则把详细文字放在图外。用户明确要求文字内容或画面密度时按其要求执行。

## 生成与检查

用户要求实际配图时，使用当前可用的图像生成工具；只要构思或提示词时，交付对应内容。检查核心关系、箭头方向和标注是否准确；再对照首要参考图检查黑色线条、橙蓝用色、文字层级、内容分区及人物是否协调，确认缩小后仍可读。

如果关系有误，先改正内容与构图；画面拥挤时删减或拆图；错字、数字及专有名词需逐项修正；风格偏移时只调整相关约束，尽量保持正确部分。重新检查后仍不准确时如实说明；不把参考图或提示词当成每次都能完全复现风格的保证。
