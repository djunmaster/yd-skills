# YD 清晰文章配图（v1.2.0）

为文章、知识笔记、前后对比和技术培训材料构思或生成配图、插图与单页信息图。默认沿用**暖白纸底 + 纯黑白粗笔手绘 + 语义锁定橙蓝点缀**的清爽知识图解风格；完整色值与人物规范见 [style-guide.md](references/style-guide.md)。

## 内容转画面流程

1. 提取受众、用途、一句核心结论与必要对象关系（不编造原文没有的数据或保证）。
2. 选择最贴合的组织方式：横向步骤（**≤ 4 步**，3 步最佳）、左右前后对比、纵向因果（移动端 `3:4`）或场景动作；超过 4 步时改为 2×2 折行或拆图。
3. 按需决定是否引入人物：当人物有助于表达动作、情绪反差或视角时加入；**拒绝光头火柴人，严格采用纯黑白粗笔特征人物**（见 `references/style-guide.md`）。
4. 选定默认画幅：文章正文 `4:3`，PPT/培训讲解 `16:9`，移动端竖屏 `3:4`。

## 内部提示词模板

```text
用途和画幅：[文章插图 4:3 / 培训图 16:9 / 移动端竖图 3:4]
核心结论：[一句话]
必须准确表现的对象、关系及阅读顺序：[具体描述]
画面构思：[主体、动作和布局；若含人物，指定不同性别、黑白发色明暗对比与眼镜/衣领等特征]
画法与配色：满幅平铺无外框投影；暖白底 #FCFBF7 + 炭黑粗线条 #1C1C1C；人物严格纯黑白不上肤色与彩色；仅用暖橙 #F06A28（动作/疑问/箭头/标题下划线）和钴蓝 #2563EB（资料/清单/依据/对勾）点缀。
文字：[逐字列出全部短标题、步骤标签与底部总结句]
避免：不复制参考图的多格黑线分栏排版；人物不上肤色/彩发/彩衣；不画光头火柴人；不画精细五指细节；无复古纸纹、厚重阴影或 3D 效果。
```

## 出图后自检门禁

1. **逐字核对**：对照提示词逐字核查全部汉字，确保零错字、零叠字、零笔画粘连。
2. **配色纯度**：确认人物完全为纯黑白粗笔（无肤色、无棕色发色），全图仅有 `#F06A28` 与 `#2563EB` 两种彩色且语义不互换。
3. **呼吸感**：四周留白充裕，箭头不压字；发现问题最多定向返修 2 次。
