# YD Illustration Skills 选型与质检路由（v1.2.1）

本目录包含三套定位互补、共享“暖白纸底 + 冷色结构 + 暖橙红单点强调”视觉基因的配图 Skill。

## 1. 场景选型路由

| 使用场景 | 推荐 Skill | 默认画幅 | 视觉气质与核心配色 |
| :--- | :--- | :--- | :--- |
| 专栏封面、观点开篇、抽象隐喻与书刊风内页 | `yd-editorial-art-illustrations` | 封面 `2:3` / 内页 `4:3` | 暖米纸 `#F0DFC1`（封面）/ `#F6EFE2`（内页）+ 深海蓝 `#1E344B` + 海蓝灰 `#6B7F93` + 朱红 `#CB4D30`（宋体标题 + 细黑正文） |
| 公众号正文概念速懂、前后对比、轻松培训讲解 | `yd-clear-article-illustrations` | 正文 `4:3` / PPT `16:9` / 竖屏 `3:4` | 暖白 `#FCFBF7` + 纯黑白粗笔特征人物 `#1C1C1C` + 语义橙 `#F06A28` / 语义蓝 `#2563EB` |
| 系统架构、AI Agent/RAG 原理、多阶段工作流白皮书 | `yd-editorial-tech-illustrations` | 横版 `16:10`（`2560x1600`） | 暖白 `#F5F2EC` + 三级卡片色阶（`#EFEBE3` / `#E6E9F8` / `#EDF2EA`）+ 深靛蓝 `#29277B` + 陶土橙 `#D7704E` |

## 2. 跨图混搭建议

- **一篇深度长文**：封面用 `yd-editorial-art-illustrations`，正文概念/对比图用 `yd-clear-article-illustrations`，核心架构与工作流用 `yd-editorial-tech-illustrations`。三者色温与克制感一致，混排不违和。

## 3. 三个 Skill 共用的最低质检门禁

1. **前置密度控制**：`clear-article` 横向 ≤ 4 步；`editorial-tech` 节点 ≤ 8 个且总字数 ≤ 180 字；超限先拆图再生成。
2. **成图逐字核对**：对照原始标题、节点名、说明文字与边标签逐项核对汉字，发现形近错字、跨行叠字或乱码直接返修，不带错字交付。
3. **满幅平铺与定向返修**：要求画面满幅平铺（无外围卡片投影画框）；单图最多针对已发现问题定向返修 2 次，若复杂反馈回环仍有粘连则优先拆图或如实说明。
