# YD 纸感艺术文章配图 · 风格与路由指南（v1.2.0）

## 1. 固定色彩规范（双底色 + 过渡色）

- **封面背景（暖米纸）**：`#F0DFC1`（细腻纸纤维与轻微印刷颗粒）
- **正文内页背景（浅米纸，新增）**：`#F6EFE2`（适配白底公众号/文档正文）
- **结构主色（深海蓝）**：`#1E344B`（主标题、主要轮廓与深色几何块）
- **过渡中间色（海蓝灰，新增）**：`#6B7F93`（次级网格、等距透视线、引导线与底部分隔线）
- **单点强调色（朱红 / 砖红）**：`#CB4D30`（全图严格控制在 1 处核心焦点）

## 2. 出版级字体混排

- **主标题与章节编号**：优雅的宋体 / 明朝体（高辨识度书刊气质）
- **副标题、要点解释与底部金句**：中细无衬线简体黑体（小屏与缩略图下笔画清晰不发虚）

## 3. 画幅分流与三锚点路由

| 画面类型 | 默认画幅 | 附加参考锚点 | 构图提醒 |
| :--- | :--- | :--- | :--- |
| 抽象封面 / 专栏头图 | `2:3` 竖版 | `assets/examples/knowledge-index-abstract-cover.png` | 允许自由平衡构图，不强制保留左侧 1/3 深蓝竖条 |
| 多载体 / 序列演进 | `2:3` 或 `4:3` | `assets/examples/content-repurposing.png` | 用柔和弧线或细引导线串联，不画粗重箭头 |
| 正文分层 / 概念内页 | `4:3` 横版 | `assets/examples/skill-interior.png` | 去掉左侧深蓝竖条，左图右文或三段横排，主图占足够视觉分量 |

## 4. 画面防雷约束

- **满幅平铺**：画面必须 100% 铺满画布边缘，禁止外围出现白色/浅色卡片边框、装裱留边或投影效果。
- **线条语义**：仅保留解释真实关系所需的线条；禁止用无意义短线、刻度、虚线、随机网格或边框填空。
