# 风格与图形选择

本指南与 [风格基准](style-anchor.png)一起使用。基准表达视觉气质，图中的 Agent Skills 标题、叠层、神经网络和圆环都不是后续文章的默认内容。

## 保持的视觉关系

| 维度 | 默认处理 | 可调整部分 |
| --- | --- | --- |
| 背景 | 暖米白纸面，细腻纸纤维与印刷颗粒 | 纹理强弱、留白位置；配色仅小幅变化 |
| 结构色 | 深海军蓝，承担文字、细线和主要深色块 | 深色块的边界与比例可配合文字和主图 |
| 强调色 | 少量朱红或砖红，形成局部焦点 | 强调对象和形状可变，不要求总是右上大圆 |
| 图形 | 精细印刷线稿，克制排线、点描或半透明层次 | 按主题更换物件、几何类型、构图与小图案 |
| 文字 | 宋体或明朝体视觉的中文标题，清楚的正文层级 | 位置、字号、字重、分行和主副标题结构 |
| 空间 | 大色块、细节与留白共同建立秩序 | 不限定左图右字、上字下图或同一图形占位 |

近似配色可参考：暖米白 `#F0DFC1`、深海军蓝 `#1E344B`、砖朱红 `#CB4D30`。这是提示词辅助值，不是对图片像素的测色结论；视觉上以基准图为准。

背景总体延续基准的冷暖、明暗与纸感。除非用户要求，不主动更换整套色系。字体由图像模型重绘时，只能要求字体气质；需要准确字体或可编辑文字时，另行使用用户指定的排版工作流。

## 先选主旨，再选图案

先问图形在表达什么，再考虑图形是否漂亮。下面是候选方向，不是必须全部出现的清单。

| 文章主旨 | 可选主图 | 可选小图案 | 需要表达的关系 |
| --- | --- | --- | --- |
| 内容复用 | 展开的刊页，或一组出版物符号 | 胶片格、索引卡、音频波形、版心标记 | 同一思想用不同媒介表达 |
| 阅读与学习 | 带批注的书页、折页或索引架 | 书签、边注、遮住答案的卡片、页码标签 | 阅读、回忆、关联与表达 |
| 知识管理 | 档案匣、索引目录或手册切面 | 标签、相互引用的页角、分类刻度 | 从分散材料形成可找到的关联 |
| 生产效率 | 排版导轨、节拍器或任务编排的器物隐喻 | 刻度、时间段、定位针、校准标记 | 组织顺序、减少切换或保持节奏 |
| 可复用 Skill | 方法卡册、工具匣或多步骤印版 | 输入标签、校准尺、检查印记 | 明确输入、执行方法与结果检查 |
| 检索与证据 | 档案页与带出处的引文插页 | 索引签、放大镜、来源标记 | 找到相关证据后形成有依据的表达 |

需要科学或几何隐喻时，可以使用网格、等高线、叠层、节点或环路，但只取与主题有关的部分。避免把这些元素组合成每篇文章都相同的主图。

一个复杂主体可以与少量辅助符号搭配；也可以像 [内容复用样张](../assets/examples/content-repurposing.png)那样，以多个不同小图案形成编辑式编排。控制线宽、投影角度、排线密度和视觉分量，使不同物件属于同一套印刷语言。

## 图文一起安排

- **封面：**突出一个主概念；短标题、必要副标题和一个主图或一组图案共同组织版面。主标题可以安静地放在留白处，也可以置于深蓝区，不强制每次做成大字报。
- **正文：**保留解释所需的段落或步骤，将文字贴近对应图案。技术关系复杂时先保证阅读顺序和箭头清楚，必要时分图；不要用装饰占掉解释空间。
- **文字密度：**用户指定的准确文案先固定；未指定时精简重复描述。需要缩略展示的封面减少小字，不靠扩大画布制造虚假的可读性。
- **细节层级：**先读标题与主图，再读辅助说明，最后看排线和微小标记。细弧线遇到文字可以局部断开。

仅做封面时不擅自编造正文；用户要求正文内容时，再根据已有材料完成对应写作。

## 调整与复用

保留背景的小幅变化和图案的充分变化这两个尺度。只调整文字结构时，说明保留哪些背景和图案；更换主题时，允许主图、构图和小图案明显变化。

对照最近可见的作品检查三点：主体是否重复、辅助图案是否机械重复、构图是否只换了标题。没有历史图片时，不假设存在跨会话图案记录；在当前系列内部检查即可。

每次直接引用风格基准。探索样张只用于说明构图或图案变化，不自动晋升为新基准。用户明确选定新方向后再调整默认依据。
