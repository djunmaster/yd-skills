# 提示词与请求示例

以下是供本次任务填写的模板，不是对已有图片生成提示词的逐字存档。生成前查看风格基准；按当前工具规范附加其实际图片文件，不把 Markdown 路径或文件名误当作已经传图。

## 文章封面

```text
制作一张正式文章封面，比例：[比例]。
附图是唯一的风格基准，参考其暖米白纸感、深海军蓝结构色、少量朱红、
精细印刷线稿、书刊式文字，以及大色块、细节和留白的平衡。
背景配色和纹理尽量保持小幅变化，允许按本篇内容重新安排文字和插画。

文章主题：[主题]
核心观点：[一句话主旨，仅供理解，不一定上图]
主图：[本篇重新选择的图形主体]
主图含义：[它如何表达核心观点]
辅助图案：[少量相关物件或符号，说明各自含义]
构图：[图文位置、阅读顺序、留白安排]

准确上图文字，仅限以下内容：
标题：[准确标题，可指定分行]
副标题：[准确副标题；不需要则省略此项]
其他文字：[确有需要的文字；不需要则省略此项]

中文标题使用克制的宋体或明朝体视觉，正文清楚；文字与插画一起构图，
不得被线条穿过或裁切。按本篇内容选择图案，不复制参考中的全部图案，
不默认使用叠层曲面、神经网络或圆环。只保留与主题有关的图案。
输出平面的完整印刷画面，保留细腻纸感，不做实物摆拍或发光界面。
```

## 正文配图

```text
制作一张与所附风格基准同系列的正文插画，比例：[比例]。
保留暖米白纸面、深海军蓝、少量朱红、细腻印刷线稿和书刊式层级。
主题：[主题]。本页要解释：[一个明确关系或一组必要步骤]。

准确上图文字：[标题、必要短句及步骤说明]
图形方案：[根据主题选择主体及辅助图案，不照搬基准插画]
文字与图形的对应：[逐项说明]
如有步骤：[顺序、输入输出及连接起终点；没有则不添加箭头]

解释文字与其对应图形保持邻近，保证阅读顺序，给中文留足边距。
背景色块与装饰服从内容，不省略必要说明来换取留白。
```

## 控制编辑

```text
图 1 是本次编辑目标，图 2 是固定风格基准。
保留：[本次要求不变的背景、配色、文字或图案]
修改：[具体问题、文字分行或需要更换的主体]
新增图案与主题的关系：[说明]
准确上图文字：[完整列出，区分保留、替换和删除内容]

只在指定范围内调整。使用基准核对配色、纸感、细线和图文气质，
不要把参考图中的示例文字带入本次成图。修改后重新核对整张图的文字和逻辑。
```

## 可直接使用的用户请求

### 内容复用：多个不同图案

```text
使用 $yd-editorial-art-illustrations，制作一张 2:3 文章封面。
主题：内容复用。核心观点：同一思想可以形成文章、视频、知识卡片和音频。
标题分两行：“一条灵感，”“四种表达。”
副标题：“内容复用 · 一次构思，多端表达”
用刊页、胶片格、索引卡和波形的组合表达四种形式。
沿用纸感、深海军蓝和朱红背景，不使用叠层网格作为主图。
```

### 学习：更换主题和主体

```text
使用 $yd-editorial-art-illustrations，为阅读方法文章制作 2:3 封面。
核心观点：读完后主动回忆，再用自己的话表达，才能发现没理解的部分。
标题：“合上书，才开始理解。”
主图尝试合拢的书、侧面的索引签与一张写到一半的回忆卡。
沿用风格基准的配色和纸感，重新安排标题位置与辅助图案。
```

以上两个请求用于说明输入方式。内置「内容复用」图片是既有探索样张；「学习」请求没有附对应的实测成图，不作为验证结果展示。
