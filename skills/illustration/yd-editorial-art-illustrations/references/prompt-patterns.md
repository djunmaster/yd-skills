# 内部生成提示词模板（v1.2.0）

```text
根据用户提供的文章文字，判断生成抽象封面（2:3 竖版，底色 #F0DFC1）或正文内页（4:3 横版，底色 #F6EFE2）。
输出 100% 满幅平铺的纯平面印刷画面，严禁外围卡片边框或微投影画框效果。
配色严格锁定：暖米纸底（#F0DFC1 或 #F6EFE2）+ 深海蓝（#1E344B）+ 海蓝灰过渡线（#6B7F93）+ 单点朱红（#CB4D30）。
字体采用出版级混排：章节编号与大标题用宋体/明朝体，副标题、要点说明与底句用清晰的中细无衬线简体黑体。
从原文提炼主旨和简洁标题，保留专名与准确事实，不补造数据。
选择一个与内容直接相关、视觉分量充足的主题主图；不强制套用左侧深蓝竖条。
仅保留解释真实关系所需的线条，无明确语义的短线、刻度、虚线和随机网格不画。
按画面类型附加对应锚点参考图，保持细腻纸张印刷质感。
成图后逐字核对全部中文标题、正文与底句，确认零错字、比例准确且视觉平衡。
```
