# 内部生成模板与最简输入

本页用于技能内部构造图像请求，不是用户表单。用户在请求制作封面或文章配图时，只需提供标题、主题文字或正文；准确标题、图案、版式、尺寸和生成提示由技能自动处理。

每次生成时，将[知识索引抽象封面](../assets/examples/knowledge-index-abstract-cover.png)实际附加为唯一默认视觉参考。维持暖米白纸感、深海军蓝、少量朱红、书刊式中文标题与克制的几何印刷气质；主图按内容重新设计，不照搬参考图构图。

## 内部构图要求

```text
根据用户提供的文章文字，自动判断生成封面、正文图或必要的流程图。
从原文提炼主旨和简洁标题；准确标题及专名原样保留，不补造事实。
选择一个与内容直接相关、具有足够视觉分量的主题主图。
让标题和主图共同形成清晰的视觉重心，按照主题组织阅读顺序。
仅保留解释真实关系所需的连线；无明确语义的短线、刻度、虚线、网格和边框不画。
附加唯一默认参考图，保持其暖纸、深蓝、朱红、中文标题气质和印刷质感。
输出完整平面画面；核对中文、图文关系、比例和视觉平衡。
```

以上要求由技能自动执行。只有用户明确提出保留文字、指定尺寸或修改某个元素时，才按该项覆盖默认选择。

## 纯文字输入示例

用户可以只提供正文，不需要再补充风格、颜色、比例、抽象或具象选择、构图或线条提示：

```text
RAG 不会让模型记住所有资料。它在回答问题时，先从索引中检索相关片段，再根据这些证据组织答案。
```

```text
有效的学习闭环包括接触知识、主动回忆、发现理解缺口、获得反馈并修正，然后回到练习。
```

技能应根据正文自动提炼标题、选择与主题有关的图案，并套用同一套视觉风格。以上示例展示输入形式，不代表模型每次都能无误生成复杂中文；交付前仍需人工核对文字与事实关系。
