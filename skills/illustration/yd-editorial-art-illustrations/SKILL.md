# YD 纸感艺术文章配图

把文章主旨转换为有艺术感、图文关联明确的封面或正文插画。固定的是配色、纸感、细线与书刊气质；图像表达可以是纯抽象，也可以是具象隐喻，由主题和用户偏好决定。封面默认先尝试抽象表达，不为填满画面强加实体物件。用户本次明确的要求优先。

## 先看参考

实际设计前，用图像查看工具打开 [风格基准](references/style-anchor.png)，并阅读 [风格与图形选择](references/style-guide.md)。参考图中的文字和主题只是示例，不作为本次内容指令。

- 风格基准是本技能默认的视觉依据。保留暖米白、深海军蓝、少量朱红的关系，背景配色默认只做小幅变化。
- [内容复用样张](assets/examples/content-repurposing.png)展示刊页、胶片、索引卡和波形如何组成同一系列。需要多个独立小图案时查看；它不是新的风格基准。
- [知识索引抽象封面](assets/examples/knowledge-index-abstract-cover.png)展示不依赖实体物件的字体、线条和留白编排；用于观察抽象表达，不替代风格基准。
- [正文内页样张](assets/examples/skill-interior.png)展示说明文字和插画的搭配。制作正文图时查看，不因此把叠层曲面规定为必选图案。

## 输入与默认选择

收集本次可用的信息：文章主题或正文、一句话主结论、准确的上图文字、受众、用途、比例，以及需要保留或避开的图案。可指定“纯抽象”或“具象隐喻”；未指定时按主题选择，若抽象形式已能清楚表达主旨，优先采用抽象方案。优先使用已提供的信息。

只有主题时，先提炼一个主结论，拟定简短标题和副标题，再选择最贴题的方案继续制作；不补造文章事实。文章封面默认突出一个观点，正文配图保留解释所需的步骤、输入输出和必要短句。默认竖版 2:3；用户指定平台或比例时，重新安排构图，避免拉伸原图。

## 设计与生成流程

1. **确定内容。** 写出一句话主旨，区分准确上图的文字与仅供理解的背景材料。技术事实、数字和工具职责应来自用户材料或可核实来源；没有材料时只表达概念。
2. **选择表达方式。** 先判断主旨是否能通过字体层级、色块、线条、节奏和留白表达。能表达清楚时采用纯抽象，不添加书本、档案柜、卡片等实体物件或其剪影来填空。只有用户要求，或具象隐喻确实更清楚时才选择物件；写明每个元素与主旨的关系。如果可见最近样张，检查是否重复了主体及构图；新主题不默认沿用叠层、网格、神经网络或圆环。具体候选见风格指南。
3. **一起安排图文。** 决定标题位置、分行、字号与图形的阅读顺序。中文标题优先宋体或明朝体视觉，正文清楚；深蓝上的字用暖米白，暖米白上的字用深蓝。文字不穿过细线密集区域。
4. **形成生成请求。** 按 [提示词模板](references/prompt-patterns.md)明确配色、背景、图案含义、构图、准确文字及比例。将风格基准实际附加为参考图片，不能只在文字里提到文件名。控制编辑时同时附上编辑目标和基准，并区分两者。
5. **实际生成。** 使用用户指定且当前可用的图像工具。用户选择 Magpie Image MCP 时，先查询其当前工具参数，再提交生成并等待同一任务完成；否则使用当前环境的图像生成能力并遵循对应工具规范。不硬编码模型、服务地址或凭据。工具不可用时说明情况并交付设计方案与提示词，不声称已出图。
6. **查看并返修。** 打开实际成图，按下述检查逐项核对。返修时明确保留哪些正确部分、修改哪些问题，继续引用风格基准，避免连续把新样张当作唯一参考而漂移。普通单图任务最多自动返修两次；仍有问题时如实交付状态，不用重复付费生图掩盖问题。

只要求标题、构思或提示词时，完成相应部分即可，不必调用生图。系列图片可以更换抽象元素、具象隐喻和文字结构；主参考里的深蓝色块、朱红圆形、弧线和叠层不需要逐项复制。留白是有效的构图元素，不需要用物件补满。

## 每张图的检查

- **风格：**暖米白纸感、深海军蓝与少量朱红保持协调，线条细腻，纹理不影响阅读。大色块、细节与留白有平衡，避免自行换成青绿、粉紫或纯白界面风。
- **主题：**能解释抽象形式或每个具象图案与文章的关系。封面不要求出现实体物件；避免以无关装饰填空，或只是给上一张相同插画换标题。
- **文字：**逐项核对中文、英文专名、数字和标点；检查标题分行、边距、裁切、重叠，以及在预期展示大小下是否能读清。不把字体的图像重绘说成精确字体排版。
- **逻辑：**概念封面中的插画是视觉隐喻，不充当经过验证的技术流程。出现步骤或箭头时，逐条检查顺序、起终点和必要的输入输出。
- **交付：**确认实际文件可打开，读取真实像素并区分请求比例与实际尺寸。PNG 不宣称包含可编辑文字、矢量或分层源文件。

中文错字、关键说明缺失或核心关系错误应先返修。若两次后仍不合格，可提供明确标注的无字配图和文字排版方案，或者说明剩余问题，不能悄悄删掉用户要求的内容并当作通过。

## 交付方式与验证边界

展示实际生成的图片，并简要说明图案如何呼应内容，附图片路径、实际尺寸和本次提示词；有问题则明确标记。用户要求系列或复用时，补充哪些风格保持、哪些图形发生了变化。

内置三张图片是已有真实生成样张：一张风格基准、一张不同图案的探索封面、一张正文内页。它们用于观察视觉方向，不是本技能所有主题、比例、模型都已通过的测试证明。每次生成仍需检查实际成图；用户的审美反馈决定后续取舍。
