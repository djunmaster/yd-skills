# 真实生图验证记录

测试日期：2026-11-16，Asia/Shanghai。当前风格版本：`1.0.0-rc.2`。当前状态：风格重复性已有实测证据，完整图解仍需人工检查，待用户审美验收；保留候选版，不标记为完全稳定。

## 实际范围与结论

完成 3 类测试，合计 14 次真实生成，覆盖 RAG、Agent 工具调用、学习流程、API 请求响应、技术文章生产 5 个主题及 3 种版式。14 张包含 rc.1、rc.2 和定向返修；只有 6 张使用统一 rc.2 提示，不能把全部图片当作最终版本独立通过样本。所有已启动的生图任务均已返回。

| 测试 | 实际生成 | 已观察结果 |
| --- | --- | --- |
| 同题独立重复 | RAG：rc.1 两张、rc.2 两张，共 4 张 | 两栏、底色、主辅色、文字与品牌职责接近；rc.2 两张都复现跨行箭头落在步骤 4 编号上方、未进入上下文图形的问题，严格端点验收不通过。 |
| 跨主题替换内容 | Agent 与学习流程：各 rc.1、rc.2，共 4 张 | 保持暖白底、靛蓝、少量橙色、左文右图和完整解释。rc.1 学习图的 6 条关系经独立人工复核未见方向错误；rc.2 学习图反馈线上又出现额外箭头。不能由主题切换时风格一致推导技术关系总是正确。 |
| 独立执行者复测 | API 泳道、技术文章章节：各初稿、返修、rc.2 回归，共 6 张 | 配色、中文和分区可复用；标题相对母版偏厚。API 三张都有关键关系问题。文章 rc.1 返修的 10 条关系通过本次人工核查，rc.2 独立重生成又出现反馈源端脱离节点。 |

**支持的结论：**固定参考图、公共前缀、模型和版式后，本次样本的视觉语言可以复用；默认 `editorial` 的两栏结构最贴近固定母版。不是像素级复制，也没有测出可外推到未来任务的稳定成功率。

**不支持的结论：**任意主题一次生成即正确、复杂流程免人工复核、字体文件与字号精确固定、Logo 与原资产逐像素一致、指定尺寸必定生效。

## 实际检查

- 实际查看成图并逐项核对底色、主辅色、文字、关系、品牌与完整度；独立复测另在 792×496 半宽下检查可读性。主标题和节点标题可辨，小号说明和页脚需要放大精读。
- 14 张生成原图均通过读取文件确认实际为 **1585×992**，请求均为 `2560x1600`。未放大后冒充原生输出。
- 模型均为 `sub2api-4/gpt-image-2.5-sunburst`，`quality=high`、每次 `n=1`。异步生成使用原任务 ID 等待，没有以重复提交代替等待。
- rc.2 两次 RAG 请求除目标路径外一致；提示词 SHA256 为 `913e1fa52f12afd35b402caea8d622ab249aba1b5fe1a6ccf4183aac23ce1d19`。两张图文件 SHA256 不同，不是复用同一文件。
- RAG 两次 rc.2 的常见背景 RGB 均为 `(249,244,239)`；母版常见背景 RGB 为 `(250,245,240)`。这证明视觉上接近暖白家族，不证明精确采用配置的 `#F5F2EC`。

## 保留的失败与发布门槛

1. RAG 折返线的源端留白、目标落点不满足 rc.2 的严格连接契约。普通横向短箭头也有节点间留白，不能声称全部几何贴合。
2. API 错误响应可能从业务处理或成功响应节点引出；错误响应框缺少出口，或返修后出现双向箭头。此题三张均失败。
3. 文章两条反馈可能被合成一条外圈线；定向返修成功一次不能证明固定提示稳定有效。
4. 学习图反馈线在 rc.2 中出现额外箭头；修复一个主题不能替代跨主题重查。
5. 章节和泳道标题偏厚、PNG 字形与 Logo 重绘，以及服务实际分辨率变化，仍属于当前能力边界。

未将失败结果升级为母版，也未删除失败图片。后续每张图都按 `SKILL.md` 验收。复杂图最多有限次定向返修；仍失败时说明具体问题及分图或可编辑排版方案，不宣称质量通过。

本次保留原提示和母版不变，只补充参考图文件校验与输入检查。校验脚本的通过仅说明请求准备可复现，不代表成图正确。
