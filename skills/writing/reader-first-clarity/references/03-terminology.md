# 03｜专业术语与新概念提示

## 识别范围
主动识别：
- 行业专有名词；
- 技术术语；
- 英文缩写；
- 产品、协议、标准或报文名称；
- 法律、财务、医疗、工程等专业概念；
- 在当前业务中有特殊含义的普通词。

## 术语处理原则
1. 正文不应依赖读者先懂专业词。
2. 能用普通语言表达的，正文优先用普通语言表达。
3. 必须保留的专业名称，集中放入「新概念提示」或用户指定的术语栏目。
4. 不要用一个未解释的术语解释另一个术语。
5. 不要把普通词全部列入术语表，避免制造新的学习负担。
6. 不确定术语的标准含义时，明确标注需核实，不要猜测。

## 推荐解释模板

| 字段 | 写法 |
|---|---|
| 名词 | 保留规范名称和缩写 |
| 通俗解释 | 用日常语言说它是什么 |
| 在本文中指什么 | 解释它在当前场景中的具体含义 |
| 简单例子 | 用一件可想象的事情说明 |
| 容易混淆的地方 | 仅在确实容易混淆时补充 |

## 解释质量标准
好的解释应当：
- 不依赖读者已经懂其他专业术语；
- 不只是把术语换成另一个抽象词；
- 能让读者说出它在当前场景中起什么作用；
- 不夸大适用范围。

## 示例
**幂等性：** 同一项请求即使因为网络问题被重复发送，系统也只完成一次实际业务处理，不会重复扣款。  
**在本文中指什么：** 企业重复提交同一笔付款请求时，银行或企业系统能够识别它已经处理过。  
**例子：** 第一次付款请求已经成功，但企业系统没有收到结果；系统再次查询或提交时，应返回第一次的处理结果，而不是再付一次钱。
