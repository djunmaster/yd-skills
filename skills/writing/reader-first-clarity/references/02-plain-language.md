# 02｜清晰语言规则

## 句子层面
优先采用“谁 + 做什么 + 对什么 + 为什么/结果”的句式。

**模糊：**
系统实现了资金管理的自动化与智能化。

**清楚：**
系统每天自动读取已授权银行账户的余额和交易记录，并把数据整理到同一个页面，方便资金人员查看各账户资金情况。

## 抽象词转具体动作
遇到以下表达时，追问“具体做了什么”：
- 提升效率
- 赋能业务
- 加强协同
- 优化管理
- 实现闭环
- 全面支持
- 深度整合
- 智能化管理
- 统一管控

这些词不是绝对不能用，但必须有具体动作、范围和结果支撑。

## 动词优先
优先使用：查看、核对、提交、审批、转账、下载、匹配、提醒、记录、计算、拒绝、退回、通知、汇总、分配。
谨慎使用：赋能、促进、助力、驱动、实现、支撑、提升。

## 段落层面
- 一段聚焦一个主要意思。
- 先给结论，再解释原因。
- 重要内容不要埋在长段落末尾。
- 列表用于并列项目，步骤用于有先后顺序的动作。
- 表格用于比较或结构化字段，不要把长篇解释硬塞进表格。

## 专业但易懂
通俗不等于随意。保留必要的专业判断、条件和准确词汇，但必须解释读者可能不熟悉的概念。
不要滥用网络用语、夸张语气、儿童化比喻或过度口语化。

## 句子检查
逐句检查：
1. 主语是谁？
2. 动作是什么？
3. 对象是什么？
4. 是否有隐藏前提？
5. 读者能否想象实际发生的事情？
6. 是否一句话塞入多个概念？
