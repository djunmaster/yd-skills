# 测试案例总览

本测试集包含 **12个前后对照案例**，覆盖10个领域、8种表达方向。案例均为教学用示例，除非另有注明，不代表真实客户、真实交易或正式专业意见。

| 编号 | 领域 | 表达方向 | 主要测试能力 |
|---|---|---|---|
| 01 | 银行/财务 | 功能卡片、业务价值、招标要求 | 抽象功能转成岗位动作和前后对比 |
| 02 | 软件/API | 技术概念解释 | 技术术语通俗化且不丢准确性 |
| 03 | 制造/质量 | 业务流程与数据解释 | 把质量管理术语转成现场动作 |
| 04 | 物流/供应链 | 异常处理流程 | 讲清触发条件、责任人和处理结果 |
| 05 | 医疗科普 | 统计概念解释 | 避免把筛查结果误解为诊断 |
| 06 | 合同/法律 | 风险条款解释 | 保留条件、范围和法律边界 |
| 07 | 网络安全 | 风险提示/操作建议 | 讲清攻击路径和用户动作 |
| 08 | 统计/科研 | 概念辨析 | 区分相关与因果 |
| 09 | 软件产品 | 需求与验收标准 | 把模糊需求变成可测试要求 |
| 10 | 采购/财务 | 操作SOP | 把专业流程转成具体步骤 |
| 11 | 管理 | 执行摘要 | 从抽象汇报转成决策信息 |
| 12 | 客户服务 | 用户操作说明 | 把含糊指引变成可执行步骤 |

## 测试方法
每个案例比较：
1. 原始表达是否难懂；
2. 改写是否保留原意；
3. 读者是否知道具体发生什么；
4. 新概念是否得到解释；
5. 是否增加了有用的场景或操作细节；
6. 是否引入原文没有的事实。

建议把这些案例作为 Skill 每次升级后的回归测试集。
